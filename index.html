02 / Sobre mí

Entender el proceso.
Construir la solución.

Soy Eduardo Araneda, ingeniero en Informática titulado con honores en AIEP, con cinco años de experiencia en desarrollo de sistemas empresariales, integraciones y despliegues, según mi trayectoria profesional. He trabajado con C#, Visual Basic, Java y SQL Server, además de JavaScript y TypeScript para construir interfaces y conectar la lógica de negocio con los datos.

Desarrollé un sistema de ventas para una empresa manufacturera que incluía cotizaciones, ventas, carga de inventario, reportes y acceso de usuarios. Esta experiencia me permitió trabajar con procedimientos almacenados y transacciones para coordinar los documentos comerciales con los movimientos de stock.

En el frontend tengo experiencia con HTML, CSS, Bootstrap, Tailwind CSS, jQuery, AJAX y Vite. Participo en distintas etapas del desarrollo, desde implementar funcionalidades e integrar sistemas hasta desplegar las aplicaciones.

También tengo experiencia en análisis técnico y funcional de sistemas del sector salud: diagnóstico de incidencias, trazabilidad de datos en Oracle y MEDISYN, revisión de código Java y PL/SQL y análisis de solicitudes y respuestas de APIs. Documento evidencias y propuestas de solución para facilitar el trabajo entre equipos.

Actualmente profundizo en arquitectura de software y toma de decisiones técnicas, con foco en la separación de responsabilidades, la consistencia de los datos y la evolución de los sistemas.

Visión de negocio

Conectar cada funcionalidad con el proceso que necesita resolver.

Cuidado por los datos

Validación, trazabilidad y consistencia en las operaciones.
